# Clean Code - Robert C. Martin
Le livre dont est inspiré le titre de ce cursus.
[Clean Code](https://g.co/kgs/UnPdz5)

## 1. Pourquoi le lire ?
Parce que c'est LA référence pour écrire du code propre. Nous n'avons pas été tout à fait honnête avec toi. Faire du clean code ne se résume pas à écrire des tests. Il y a tellement de choses qui compte.
Robert C. Martin, alias "Uncle Bob", et réputé internationnallement pour son point de vue sur "Comment écrire du code proprement". Il est le fondateur de la philo du Software Craftmanship.

Son livre est illustré systématiquement d'exemple. Alors certes les exemple sont en Java. Mais crois moi, c'est même encore mieux. Car à travers la lecture, l'auteur te fera lire du code dégueux. Puis te montrera le même code mais clean... et même écrit en Java, tu verras ce veut réellement dire `clean`.


## 2.Qu'est ce que tu vas y trouver ?
En gros tu vas y trouver les sujets que je n'ai pas abordé par choix pendant ce cursus :
- Comment réfléchir au nom de tes variables
- Comment réfléchir à l'intention de ton code
- Comment écrire correctement ses uses cases
- Savoir comment écrire ses tests et pourquoi.
- Comment aborder un refactoring dans un code que l'on ne connait pas.
- Comment avoir la philo du "Boy Scout" et laisser toujours le code plus propre qu'on ne l'a trouvé initialement.

Crois moi, si tu as le temps, tes futurs lead ou CTO te remercieront de l'avoir lu.

Ensuite, tu pourras aussi t'attaquer au livre [Clean Coder : A code of conduct for professionnal](https://g.co/kgs/MFSrBa). Souvent vendu en bundle avec Clean Code d'ailleurs.
Il s'attardera plus sur la posture professionnelle que tout dèv doit avoir pour, justement, pouvoir faire du clean code.
